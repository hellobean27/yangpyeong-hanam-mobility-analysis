# 양평군–하남시 광역 생활이동 분석

2026년 **「AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전」** 제출 분석을 재현하기 위한 저장소입니다.

## 1. 분석 질문

> 대중교통 접근성이 낮고 자동차 의존도가 높은 양평군에서, 실제 생활이동 수요에 맞춘 광역대중교통 재설계가 **이동격차를 완화하면서 자동차 이동과 탄소배출을 동시에 줄일 수 있는가?**

분석은 다음을 확인합니다.

- 양평군 12개 읍·면 중 하남시 이동이 어디에서 집중되는지
- 하남시 내부에서 어떤 목적지로 이동이 집중되는지
- 이동 목적이 출퇴근에 국한되는지
- 차량 의존도와 장거리·장시간 이동 부담이 어느 정도인지
- 차량 이용 이동의 5%·10%·20%가 대중교통으로 전환될 때 기대효과가 어느 정도인지
- 실제 버스 공급이 서울행과 하남행에서 어떻게 다른지
- 고정형 간선·DRT/지선·환승연계를 어떤 읍·면에 적용할지
- 현행 8-8의 서비스 공백과 실증 시나리오의 접근성 대리지표 차이
- 차량수단 이용 인·km의 5%·10%·20%를 버스로 전환할 때의 표준계수 기반 온실가스 감축 잠재량

## 2. 핵심 결과

| 지표 | 결과 |

| 차량 이용 비중(2026-08-24~30) | **98.76%** |
| 대중교통 이용 비중 | **0.91%** |
| 평균 차량 이동거리 | **24.009 km** |
| 평균 차량 이동시간 | **67.47분** |

## 3. 데이터

### 수도권 생활이동

서울시·KT가 개발한 수도권 생활이동 데이터를 사용했습니다. 공식 데이터 설명은 일별·시간대별 이동과 출근·등교·쇼핑·관광·병원·귀가·기타 7개 이동목적을 제공합니다.

- 서울 데이터 허브: https://data.seoul.go.kr/bsp/wgs/dataView/data300View/20062.do

### 이동수단·거리·시간

2026-08-24~2026-08-30 기간의 수도권 생활이동 이동수단 자료를 별도로 분석했습니다.

**중요:** 6월 OD/목적 데이터와 8월 이동수단 데이터는 서로 다른 기간입니다. 동일 개별 이동으로 직접 결합하지 않고, 각각 **생활이동 구조**와 **차량 의존 특성**을 확인하는 독립 지표로 사용합니다.

### 버스 공급

양평군청 시내버스 공식 시간표를 기준으로 대표 노선 운행횟수를 비교했습니다.

- 양평군청 시내버스: https://www.yp21.go.kr/www/contents.do?key=1500

대표적으로 공식 시간표상:
- 8-8 문호리 → 하남: 평일 3회
- 2000-2 양평터미널 → 하남 미사권 → 잠실: 평일 1회
- 2301 문호리 → 잠실: 15회
- G9311 용문·양평 → 잠실: 평일 8회

## 7. 해석상 주의

- 생활이동 값은 통계적 방법으로 추정된 이동량이며 실제 개별 이용자 수와 동일하다고 단정하지 않습니다.
- 정책 전환율 5%·10%·20%는 **관측 결과가 아니라 정책 시나리오**입니다.
- 기존에 `vehicle-km`로 표기했던 `CNT × MOVE_DIST`는 차량대수가 아니라 추정 이동인구에 거리를 곱한 값이므로 **vehicle-mode person-km(차량수단 이용 인·km)** 로 수정했습니다.
- 온실가스 감축량은 한국환경공단 2024.10 가이드의 승용차 0.2111, 버스 0.0291 kgCO₂eq/인·km를 적용한 **표준계수 기반 정책 시나리오**이며 실제 실증 노선의 차량형식·승차율·공차운행을 직접 측정한 결과가 아닙니다.
- 연간 감축량은 동일한 주간 패턴이 52주 유지된다는 **단순 연환산 추정치**입니다.
- 수요가중 다음 직결버스 대기시간은 실제 승객의 관측 대기시간이 아니라 시간대별 차량 이동수요를 기존/제안 출발시각에 겹친 **서비스 접근성 대리지표**입니다.
- “대중교통 공급 부족이 차량 의존의 원인”이라는 인과관계는 현재 자료만으로 확정할 수 없으며, 본 분석에서는 **정책 가설**로 다룹니다.
- 원 API 응답의 목적 코드 숫자와 한글 목적명을 다시 매핑할 경우 공식 코드북 확인이 필요합니다. 본 저장소 CSV는 보고서에서 확정한 집계 목적명 기준입니다.

## 8. 원자료 공개 범위

공모전 재현성을 위해 보고서에 사용한 **집계 입력값과 분석 코드**를 공개합니다. 원본 API 응답 JSON 및 대용량 ZIP 파일은 저장소에 포함하지 않습니다. 원자료를 보유한 경우 동일한 집계 규칙으로 입력 CSV를 교체하여 분석을 재실행할 수 있습니다.


## 9. RQ4 정책 시나리오 요약

읍·면별 하남 이동량의 상위 25% 기준과 주요 고정거점 보유 여부를 결합하면 다음과 같이 분류됩니다.

| 서비스 유형 | 읍·면 수 | 하남 이동 비중 | 인구 비중 | 정책 역할 |
|---|---:|---:|---:|---|
| fixed_trunk | 3 | 65.75% | 48.97% | 양서면·양평읍·서종면 중심 정기형 광역 간선 |
| drt_feeder_priority | 4 | 14.11% | 18.59% | 고정거점 미보유 지역의 DRT/지선 우선 연계 |
| timed_transfer | 5 | 20.15% | 32.45% | 기존 철도·버스 거점과 간선의 시간표 연계 |

현행 8-8(07:35·14:20·18:25)은 최대 확인 공백이 405분입니다. 분석용 실증안은 06:30~20:30 사이 2시간 간격 8회로 설정했습니다. 이는 **정책효과 비교용 시나리오**이며 실제 노선 확정안이 아닙니다.

한국환경공단의 대중교통 이용 확대 감축원단위(승용차 0.2111, 버스 0.0291 kgCO₂eq/인·km)를 적용하면 차량수단 인·km의 5%·10%·20% 전환 시 주간 순 감축 잠재량은 각각 약 **13.65 / 27.29 / 54.58 tCO₂eq**입니다.
